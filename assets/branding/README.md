# Kit de marca · Qlq el Dólar

Glifo **q$**: la última "q" de *qlq* con la barra del signo de dólar. Trazos redondeados, sin relleno.

## Colores
| Uso | Hex |
|---|---|
| Teal (primario) | `#14B8A6` |
| Teal claro (acento) | `#2DD4BF` |
| Teal profundo | `#0F766E` |
| Azul (fin del degradado) | `#2563EB` |
| Navy (fondo oscuro) | `#0B1220` |
| Dorado (detalle) | `#F5B301` |

Degradado del ícono: 135°, `#14B8A6 → #2563EB`.

## Tipografía
Wordmark en **Poppins Bold** (letter-spacing -2.5%). Subtítulos en Poppins Medium, mayúsculas, tracking amplio.

## Archivos
- `icon/` — ícono de app (degradado, navy, blanco), glifo suelto (blanco/navy/teal) y `playstore-512.png`.
- `wordmark/` — lockup horizontal (fondo oscuro, claro, transparente y monocromo) y versión apilada.
- `social/github-banner.png` — banner 1280×640 para el README / redes.

Cada pieza está en **SVG** (fuente editable, escala infinita) y **PNG** de alta resolución.

## Reglas rápidas
- Zona de protección alrededor del ícono: mínimo 25 % de su lado.
- No estirar, no rotar, no cambiar el degradado por otros colores.
- Sobre fotos o fondos complejos usar la versión monocroma.
- Tamaño mínimo del glifo: 16 px; del wordmark: 120 px de ancho.
